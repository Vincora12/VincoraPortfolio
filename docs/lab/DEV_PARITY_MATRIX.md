## Duplication bans

- Day advancement exists only in SYSTEM.LAB / SIMULATION.
- Rarity threshold tuning exists only in CREATION.LAB.
- Bio controls exist only in CREATION.LAB.
- Voice DNA controls exist only in CREATION.LAB.
- Current Mood/Memory controls exist only in SYSTEM.LAB.
- Asset generation/import controls exist only in CREATION.LAB.
- Model/provider selection exists only in SYSTEM.LAB / AI.


## Important behavior classification

- ResolverSection is a DEV-accessible **optional AI creation tool today**, not proof that hatch automatically calls it.
- BioSection AI rewrite is optional; deterministic Bio is automatic.
- PromptPreview AI rewrite is optional; deterministic prompt compilation is automatic.
- Image generation is part of the automatic hatch/evolution background path when credentials are available.


## DESIGN.LAB relationship

DESIGN.LAB does not absorb creation/system DEV functions.

It owns UI inspection and UI modification:
- real-screen preview;
- component selection;
- token inspection;
- layout inspection;
- contextual Design AI;
- design patch preview/A-B/history.

Existing product/domain controls remain in CREATION.LAB or SYSTEM.LAB.
